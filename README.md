# Личный кабинет с оценками

Небольшое веб-приложение на Node.js/Express:

- вход по логину и паролю (пароли хранятся в виде bcrypt-хэшей, сессии на cookie);
- личный кабинет студента со списком оценок по предметам;
- админ-панель для выставления/изменения оценок студентам (доступна только роли `admin`).

## Установка и запуск

```bash
npm install
npm run seed   # создаёт src/data/db.json с тестовыми пользователями
npm start      # запускает сервер на http://localhost:3000
```

## Тестовые учётные записи

| Логин   | Пароль       | Роль    |
|---------|--------------|---------|
| admin   | admin123     | админ   |
| ivanov  | student123   | студент |
| petrova | student123   | студент |

После первого входа рекомендуется сменить пароли (для этого сейчас нужно отредактировать `src/seed.js` и заново выполнить `npm run seed`, либо добавить страницу смены пароля).

## Технические детали

- Хранилище — JSON-файл `src/data/db.json` (создаётся командой `npm run seed`, в git не коммитится).
- Пароли хэшируются `bcryptjs`, в открытом виде нигде не хранятся.
- Все страницы, кроме `/login`, требуют авторизации; `/admin/*` — только для роли `admin`.
- Сессии подписываются секретом из переменной окружения `SESSION_SECRET` (если не задана — генерируется случайный секрет при каждом запуске, из-за чего сессии не переживут перезапуск сервера; для продакшена задайте `SESSION_SECRET` явно).
