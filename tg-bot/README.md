# Telegram-бот с оплатой через ЮKassa

Бот на [Telegraf](https://telegraf.js.org/) с приёмом платежей 5 / 50 / 100 ₽ через ЮKassa.
Работает через long polling — публичный сервер/домен не нужен, можно запускать
на обычном домашнем ПК.

## Как это работает

1. `/start` — показывает три тарифа.
2. При выборе тарифа бот создаёт платёж в ЮKassa и присылает ссылку на оплату.
3. После оплаты пользователь жмёт «Я оплатил» — бот проверяет статус платежа
   через API ЮKassa. Также раз в `POLL_INTERVAL_MS` бот сам опрашивает все
   незавершённые платежи — можно и не нажимать кнопку.
4. Как только платёж переходит в статус `succeeded`, пользователю выдаётся
   доступ (срок хранится в `data/users.json`), бот присылает подтверждение.
5. `/status` — показывает, до какой даты активен доступ.

Тарифы и срок доступа по каждому из них настраиваются в `src/config.js`
(массив `PLANS`) — сейчас это условные 1 / 30 / 90 дней, поменяйте под
свою задачу.

## Установка

```bash
cd tg-bot
npm install
cp .env.example .env
```

Заполните `.env`:

```
BOT_TOKEN=токен от @BotFather
YOOKASSA_SHOP_ID=ваш shopId
YOOKASSA_SECRET_KEY=ваш секретный ключ
```

**Важно:** `.env` и `data/*.json` (там хранятся платежи и доступы пользователей)
в git не попадают (см. `.gitignore`). Никогда не коммитьте реальные ключи.

## Запуск

```bash
npm start
```

## Ограничения текущей реализации

- Хранилище — плоские JSON-файлы, годится для небольшого числа пользователей.
  Для продакшена стоит перейти на настоящую БД (SQLite/Postgres).
- Подтверждение оплаты идёт через опрос API (polling), а не через вебхук
  ЮKassa — это специально сделано, чтобы бот работал без публичного HTTPS-адреса.
  Если понадобится вебхук (например, при деплое на сервер) — используйте
  уведомления ЮKassa (`POST /v3/payments` -> `webhook` в личном кабинете) и
  добавьте HTTP-эндпоинт, который дергает ту же логику выдачи доступа.
